User visits page\n   ↓\n2. lastRefreshTime loaded from localStorage (or null if first visit)\n   ↓\n3. nowTick updates every 1 second\n   ↓\n4. Badge calculates: diffMs = nowTick - lastRefreshTime\n   ↓\n5. Badge displays relative time & color based on age\n   ↓\n6. User clicks \"Refresh News\"\n   ↓\n7. API called, lastRefreshTime updated\n   ↓\n8. Badge reappears with \"Just now\"\n   ↓\n9. Loop continues every second\n```\n\n### Real-Time Updates\n- Updates every second without page reload\n- No API calls needed (all client-side)\n- Uses existing `nowTick` state (1s interval)\n- Smooth transition: \"Just now\" → \"1s ago\" → \"2s ago\" etc.\n\n---\n\n## 📊 Technical Specifications\n\n### Browser Support\n- ✅ Chrome/Chromium (full support)\n- ✅ Firefox (full support)\n- ✅ Safari (full
