## Instructions Provided to User
Provided step-by-step guidance for setting up and running the application locally:

### Backend Setup
1. `cd backend`
2. `pip install -r requirements.txt`
3. Create `.env` from `.env.example` with required values (MONGODB_URL, DATABASE_NAME, SECRET_KEY)
4. Run `uvicorn app.main:app --reload` (API available at http://localhost:8080)

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. Create `.env` with `REACT_APP_LD_CLIENT_SIDE_ID` (can be dummy value for auth-only testing)
4. Run `npm start` (app available at http://localhost)

### Usage
- Register via frontend at `/register` or via API: `POST http://localhost:8080/api/v1/auth/register`
- Login via frontend at `/login` or via API: `POST http://localhost:8080/api/v1/auth/login`
- User data stored in MongoDB database `news_intelligence`, collection `users` (passwords hashed with bcrypt)

### Alternative: Docker Deployment
1. Backend: Copy `.env.example` to `.env` and fill in values
2. Frontend: Create `.env` with `REACT_APP_LD_CLIENT_SIDE_ID`
3. From project root: `docker-compose up --build`
   - Backend API: http://localhost:8080
   - Frontend: http://localhost
